# BEC-305 - Microprocessors and Microcontrollers\n\n**Credits: 5**\n\n## UNIT-I
Introduction to Microprocessors: evolution, architecture and operations, memory and I/O devices. 8-bit
Microprocessor (8085): signal description, register organization, architecture, memory/I/O interfacing, assembly
language programming.
## UNIT-II
16-bit Microprocessors (8086/8088): architecture, physical address segmentation, memory organization, bus
cycle, addressing modes, difference between 8086/8088, introduction to 80186/80286, assembly language
programming.
## UNIT-III
Introduction to Microcontrollers: survey of 4/8/16/32-bit microcontrollers, comparison with microprocessors, 8051
family overview, hardware architecture, memory organization, I/O ports, timers/counters, interrupts.
## UNIT-IV
8051 Assembly Language Programming: structure, assembling and running programs, addressing modes;
instruction set - arithmetic/logical operations, jump/call instructions, I/O programs, single bit instructions,
timer/counter programs.
