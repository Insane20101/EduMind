Either I give a Class C address; Class C is insufficient because Class C has a very small number of IP addresses. According to user demand we are not providing IP addresses; already we have manually cut beforehand that this has this many IP addresses, this many in this, this many in this class. Maintenance will be easier in small networks. To remove or reduce this maintenance cost we can use the funda of subnetting here. What does subnetting do? It divides a large network into small networks. So maintaining small networks is easy compared to a big network. 

It is more prone to errors.
