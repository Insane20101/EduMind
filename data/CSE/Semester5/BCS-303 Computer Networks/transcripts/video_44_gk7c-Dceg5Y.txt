So what is this value? This is the Network ID. This means this IP address belonged to which network? It belonged to this network: `194.2.3.0`. 1. **First address (`.0`):** This IP address is first. This we will not give to any host because it represents this network.

Don't touch network bits, just copy them as they are, because if you change the network bit, then the network will change, and you will reach from some ABC organization to an XYZ organization. * Do not give the last one to any user because it is the direct broadcast address. This one, so that the router knows that this packet is to be provided to all hosts.
