Hello friends, welcome to Gate Smashers. The topic is cryptography. Cryptography is a technique through which we can convert plain text to cipher text, and then convert cipher text back to plain text. 

Plain text is a normal message that anyone can read and understand. Cipher text, on the other hand, is a secret message. Anyone can see the message, but the meaning of what is written can never be understood. 

We use cryptography to achieve confidentiality. When we talk about network security, there is an important concept called the CIA triad: Confidentiality, Integrity, and Availability. The "C" in CIA stands for confidentiality. What we understand by confidentiality is not necessarily that no one can intercept our message. If I am sending a message to a receiver sitting 1,000 kilometers away, someone along the way might try to intercept or hack my message in an unauthorized way. However, this does not mean confidentiality is breached or reduced to zero. Anyone can capture a message on the internet because all devices are connected in a vulnerable manner. "Vulnerable" means that any person with some hacking skills can capture your packet. But taking the packet or the data does not mean they can read and understand it. If the unauthorized person can also read and understand the data, then confidentiality is zero. But if someone merely traces your packet on the way, tracing does not mean they understand what is written inside it. That is the true meaning of confidentiality.

When a sender wants to send a plain text—which is a normal, readable message—to a receiver, there is no dedicated wire between them. We do not have dedicated wires on the internet. For example, if I have to send an email from India to California, there is no dedicated line or link. We use the internet, meaning when the message exits our machine, we do not control which routers or nodes it passes through. This medium or channel is inherently unsecure. Because we are sending a message over an unsecure channel, any unauthorized person can intercept it. There is no way to prevent them from taking the message, but if we send it as plain text, anyone who intercepts it can also read and understand it. We do not want this, and that is why we use cryptography.

Before sending the plain text, the sender uses an encryption method. In encryption, we use various algorithms. The most important part of these algorithms is the key. Think of it like a lock we put on our house, which is locked and opened with a key. Similarly, the algorithm locks the message with a key. Once locked, the plain text becomes cipher text—a secret message that nobody can read or understand. When we send this message over an unsecure channel, anyone can intercept it along the way. However, the original message, let's call it $M$, is no longer sent as $M$. It has been converted into cipher text, which we can call $M'$. Because we are not sending the plain text as-is, any unauthorized person who intercepts it on the way will only see $M'$. When the message reaches the receiver, they must decrypt it. Since no unauthorized person can understand the cipher text, the legitimate receiver needs a way to read it. The receiver decrypts the message, which means converting $M'$ back to $M$ (converting cipher text back to plain text). Thus, the sender performs encryption, the receiver performs decryption, and after decrypting, the receiver reads the plain text. Along the way, any unauthorized user only sees $M'$, while the actual message is $M$.

Cryptography is not a new term, although it has become highly popular today due to the growing importance of network security and cybersecurity. Cryptography actually dates back to the time of Julius Caesar, the King of Rome. He used a technique called Caesar's cipher to communicate with other kings. They encoded messages in such a way that no unauthorized person could decode them. Even if an enemy attacked the message carrier and took the message, they could not read it. To read the message, they would have to decrypt it, which required a key that they did not possess. This is the essence of cryptography and encryption, and it is how we achieve confidentiality.

In cryptography, we have an important concept: we can use cryptography in two ways, symmetric and asymmetric. Symmetric key cryptography means using the exact same key for both encryption and decryption. This is just like the lock we use at home: the same key used to lock it must be used to unlock it. You cannot unlock it with a neighbor's key. Asymmetric cryptography, on the other hand, uses two different keys: we lock the message with one key and unlock it with a different key.
