So what will happen due to this? Then, efficiency: this is a very important formula of efficiency. Efficiency of Stop & Wait is $1 / (1 + 2x)$, where $x = \text{propagation delay} / \text{transmission time}$. The sender window size that I have written here is $2^k - 1$. What is $k$ here? $k$ is the number of bits required to represent the window size. Then, here we use the Cumulative Acknowledgement system. Cumulative acknowledgement means let's say I send packets 1, 2, 3, 4. Then the acknowledgement is always of the next expected bits. This point you remember: that whenever, let's say we send frame number 1, 2, 3. So when these 1, 2, 3 are received by the receiver, then what acknowledgement will it send? It will send acknowledgement of the next expected bytes. Next expected byte means I have received 1, 2, 3; now I want frame number 4, the next one. We always send the next acknowledgement. Here we use cumulative acknowledgement. Its advantage is that the traffic in the network will reduce. Like for example, if I am sending 100 packets from Chandigarh to Delhi everyday—at the same place I send 100 packets, then what may happen? Then, if we talk about Selective Repeat, in Selective Repeat also we send multiple frames. Selective Repeat is actually a mixed version of these 2. It says send multiple frames at a time. Along with this, I will tell you one more point: it can also send a negative acknowledgement. Negative acknowledgement means what?
