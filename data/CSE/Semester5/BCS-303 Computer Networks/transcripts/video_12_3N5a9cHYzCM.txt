If we talk in technical terms, then forwarding: do hubs do forwarding? Yes. Means if A wants to send data to D, when A sends the data, when it reaches the hub, will the hub forward it ahead? Yes. It'll obviously do forwarding. 

Next is filtering. Filtering is important. Collision domain: if we talk about the collision domain in this hub, collision is not possible outside, but is it possible in the hub? Yes. If A sends a message, then the signal reaches here.
