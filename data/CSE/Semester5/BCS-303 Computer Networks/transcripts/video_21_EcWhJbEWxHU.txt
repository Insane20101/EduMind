Hello friends, welcome to Weights Measure. The topic is types of casting in computer networks. Generally, in computer networks, we use terms like unicasting, broadcasting, and multicasting. Although this topic is basically a part of computer networks, when we start studying computer networking, knowing about these terms is very important because these terms frequently appear in theoretical questions. There is a high chance of such questions in exams like UGC NET, KVS, and from the point of view of GATE as well. Even otherwise, if you are studying computer networks, you must clear these basic concepts: what are unicasting, broadcasting, and multicasting?

Let's start with unicast. What is the main purpose of computer networks? We are sharing data; we are sharing files. So, when we talk about sharing a file, unicast means a one-to-one communication. Unicast means one-to-one, 1-to-1. One-to-one means one person is sending data to another person. That is a kind of one-to-one communication. 

For example, suppose we have Network A, and let's say its address is 90.0.0.0, which is a Class A network. And we have Network B, and there are a number of hosts in it. If a host, let's say m1, wants to send data to m2 within this network—meaning one person is sending a message to another person—that is a kind of one-to-one communication, which we use on a daily basis. Whenever we send messages from WhatsApp, our messages are sent one-to-one. Although we can send messages to groups as well, we generally use one-to-one communication. This is the simple meaning of unicast.

Next, what is the meaning of broadcast? Actually, broadcast is basically of two types: limited broadcast and direct broadcast. 

Limited broadcast means broadcasting a message to everyone within a local network. For example, if a person inside Network A wants to send a message to all the other hosts inside Network A only, that is called a limited broadcast. For this, we use the IP address 255.255.255.255, which means all ones. All ones means the message is sent to all hosts within the network.

Direct broadcast means if a person (m1) inside Network A wants to send a message to all hosts in another network (Network B), in that case, we call it a direct broadcast address. In the case of a direct broadcast, suppose we want to send a message to all hosts in Network B from Network A, then the destination address would be 92.255.255.255. Here, 90.0.0.0 is the network ID of Network A, and if we talk about Network B having network ID 92.0.0.0, then 92 followed by all ones becomes the direct broadcast address of that network. Similarly, for Network A, the direct broadcast address would be 90.255.255.255.

Then comes multicast. What is multicast? In multicasting, we generally use terms like unicast or broadcast, but multicast means sending a message to a group. What is a group? A group consists of a similar kind of people. For example, a research group. If we talk about a real-life environment, a news channel is a broadcast because it sends data to everyone. But if I send an email to a specific group of people where email groups are created, that becomes our multicast stream, where we target a particular group of similar kinds of people. 

Multicasting falls between unicasting and broadcasting. For multicasting, we use IGMP (Internet Group Management Protocol). If we talk about classful addressing, Class D is specifically reserved for multicasting. I have already made a video on Class D, and I will share the link in the description. Class D was actually dedicated to groups so that we can target similar kinds of people in groups. 

These are the basic concepts of unicasting, broadcasting, and multicasting. You must know about these concepts so that you can use them in further questions. Thank you!
