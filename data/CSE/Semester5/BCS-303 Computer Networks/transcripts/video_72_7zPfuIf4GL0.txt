### Data Transfer

Before data transfer, I have to tell you that when TCP establishes a connection, what happens through it is that both the client and server reserve their resources. What is meant by reserving the resources? It is that they have already established their buffers. One has kept its buffer, the other has kept its bandwidth, and they have reserved their resources. They are waiting for the data to come to them. 

The first important point of TCP data transfer is that it is a duplex mode. What is meant by duplex? It is that data transfer will take place from client to server and also from server to client. This means the connection is like this: from client to server and from server to client also. This means the client can send data to the server, and at the same time, the server can also send data to the client. That is called full duplex. This means both the client and server can communicate with each other and do data transfer.

### Piggybacking vs. Pure Acknowledgement

The first point is: When we send acknowledgment, we can send it by two methods. 

#### 1. Piggybacking
What is meant by piggybacking? When we are sending data, with data we are sending acknowledgment also. See, we've sent the data of 10 bytes, and with that, we have sent the acknowledgment also that I have accepted your data, now I am sending data. 

Like this only, before that, the client said, "Take this data from my side, and this is the acknowledgment of the last data you have sent." Here, the server gets to know that its data has reached. In the next packet, the client gets to know its data has reached, and data has come from the server also. 

So when we send data and acknowledgment together, that is called a piggybacked package. Why do we use this piggybacking? Obviously, for reducing the traffic of the network. Otherwise, what will happen? You have sent data, and then acknowledgment. Then data, then acknowledgment. So, obviously, your traffic, your network—you are sending data and acknowledgment in the network in different packets. So the network data will have many packets. For reducing that, we are using piggybacking, in which we send data and acknowledgment together.
