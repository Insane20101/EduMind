# BCS-303 - Computer Networks\n\n**Credits: 4**\n\n## UNIT-I
Data Communication Concepts, networks and layered architecture, protocols and standards, OSI and TCP/IP
reference models, transmission media, network topology, multiplexing, circuit/packet switching, LAN and
interconnection devices.
## UNIT-II
Medium Access Sub Layer: channel allocation, LAN protocols, ALOHA protocols, CSMA/CSMA-CD,
collision-free protocols, IEEE standards, Ethernet, FDDI. Data Link Layer: design issues, error
detection/correction, sliding window protocols, HDLC.
## UNIT-III
Network Layer: packet switched networks - IP, ARP, RARP, DHCP, ICMP, queuing discipline, routing
algorithms, congestion control, internetworking, TCP/IP protocol, IPv4 and IPv6.
## UNIT-IV
Transport Layer: design issues, connection management, UDP, TCP, adaptive retransmission, congestion
control/avoidance, QoS. Application Layer: DNS, Email, FTP, HTTP, introduction to cryptography and network
security.
