# BCS-301 - Principles of Operating Systems
## Complete Unit-Wise Question Bank (Theory + Numericals, Basic → Advanced)

> **Course:** BCS-301 - Principles of Operating Systems  
> **Credits:** 4  
> **Coverage:** Strictly mapped to the syllabus.

## Syllabus Reference
### UNIT-I
Operating Systems Overview: components, goals, system structures, user services; interrupt systems and device programming, hardware support, context switching, privileged instructions.  
### UNIT-II
Memory Management: fetch, placement, contiguity, relocation, paging and virtual memory, TLB, single/multi-level page tables, segmentation. Virtual Storage Management: storage hierarchy, cache usage, page replacement, working sets.  
### UNIT-III
Concurrency: critical section problem, process synchronization, semaphores, monitors, IPC, RPC. Deadlock: prevention, avoidance, detection, recovery. Process/Thread Management: states, transitions, CPU scheduling algorithms.  
### UNIT-IV
Physical Storage Management: disk scheduling algorithms, performance and reliability. File System Organization: boot record, directory organization, file descriptors, access control, backup. System Security: least privilege, threats, protection mechanisms.
