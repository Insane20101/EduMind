# BCS-440 - Project Part-II
## Complete Unit-Wise Question Bank (Theory + Numericals, Basic → Advanced)

> **Course:** BCS-440 - Project Part-II  
> **Credits:** 3  
> **Coverage:** Strictly mapped to the syllabus.

## Syllabus Reference
Continuation of the final year group project: detailed design, implementation, testing and documentation, culminating in a project report and demonstration.

## UNIT I — Project Design and Planning
### Section A: Definitions & Concept Questions (Basic, 2–3 Marks)

1. **[Unit I | Topic: Project Design | Type: Theory | Difficulty: Basic]**  
   What is project design, and why is it important in software development?

2. **[Unit I | Topic: Project Planning | Type: Theory | Difficulty: Basic]**  
   Define project planning. What are the key components of a project plan?

### Section B: Computational & Applied Problems (Intermediate, 7 Marks)

1. **[Unit I | Topic: Work Breakdown Structure | Type: Applied | Difficulty: Intermediate]**  
   Create a Work Breakdown Structure (WBS) for a simple software development project.

2. **[Unit I | Topic: Gantt Chart | Type: Applied | Difficulty: Intermediate]**  
   Given a list of project tasks with estimated durations, create a Gantt chart to represent the project timeline.

### Section C: Advanced Theory & Numericals

1. **[Unit I | Topic: Risk Management | Type: Theory | Difficulty: Advanced]**  
   Discuss the various types of risks that can arise during a software project and how they can be mitigated.

2. **[Unit I | Topic: Agile Methodology | Type: Theory | Difficulty: Advanced]**  
   Explain the Agile methodology and its advantages over traditional project management approaches in software development.

## UNIT II — Implementation and Testing
### Section A: Definitions & Concept Questions (Basic, 2–3 Marks)

1. **[Unit II | Topic: Software Implementation | Type: Theory | Difficulty: Basic]**  
   What is software implementation, and what are the key steps involved in this process?

2. **[Unit II | Topic: Testing Levels | Type: Theory | Difficulty: Basic]**  
   Define unit testing and integration testing. How do they differ?

### Section B: Computational & Applied Problems (Intermediate, 7 Marks)

1. **[Unit II | Topic: Test Case Design | Type: Applied | Difficulty: Intermediate]**  
   Design five test cases for a login module of a web application.

2. **[Unit II | Topic: Bug Tracking | Type: Applied | Difficulty: Intermediate]**  
   Describe the process of bug tracking and present a sample format for a bug report.

### Section C: Advanced Theory & Numericals

1. **[Unit II | Topic: Testing Strategies | Type: Theory | Difficulty: Advanced]**  
   Compare and contrast black-box testing and white-box testing strategies.

2. **[Unit II | Topic: Continuous Integration | Type: Theory | Difficulty: Advanced]**  
   Explain the concept of Continuous Integration (CI) and its significance in modern software development practices.

## UNIT III — Documentation and Reporting
### Section A: Definitions & Concept Questions (Basic, 2–3 Marks)

1. **[Unit III | Topic: Project Documentation | Type: Theory | Difficulty: Basic]**  
   What is project documentation, and why is it crucial for a software project?

2. **[Unit III | Topic: Report Structure | Type: Theory | Difficulty: Basic]**

### Section B: Computational & Applied Problems (Intermediate, 7 Marks)

1. **[Unit III | Topic: Documentation Tools | Type: Applied | Difficulty: Intermediate]**

2. **[Unit III | Topic: Writing Recommendations | Type: Applied | Difficulty: Intermediate]**

### Section C: Advanced Theory & Numericals

1. **[Unit III | Topic: Technical Writing | Type: Theory | Difficulty: Advanced]**

2. **[Unit III | Topic: Project Evaluation | Type: Theory | Difficulty: Advanced]**
