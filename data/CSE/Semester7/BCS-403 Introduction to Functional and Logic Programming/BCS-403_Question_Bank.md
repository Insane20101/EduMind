# BCS-403 - Introduction to Functional and Logic Programming
## Complete Unit-Wise Question Bank (Theory + Numericals, Basic → Advanced)

> **Course:** BCS-403 - Introduction to Functional and Logic Programming  
> **Credits:** 4  
> **Coverage:** Strictly mapped to the syllabus.

## Syllabus Reference
- UNIT-I: Distinctive features of functional programming, recursion, tail recursion, higher order functions, lazy evaluation, types in functional programming, mathematics of functional programming (lambda calculus).
- UNIT-II: Introduction to Haskell, defining functions (guards, pattern matching, recursion), lists/strings/tuples, types and polymorphism, higher order functions, lazy evaluation and infinite data structures.
- UNIT-III: Logic and Reasoning, logic programs, Prolog syntax and primitives, tail recursion, accumulators, difference lists.
- UNIT-IV: Applications of Logic Programming (theorem proving, NLP, expert systems), implementation of logic programs, Constraint Logic Programming: constraint satisfaction and propagation.
