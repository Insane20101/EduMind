# BCS-402 - Cryptography and Information Security\n\n**Credits: 4**\n\n## UNIT-I
Introduction to Cryptography, attacks, services and mechanisms, conventional encryption model, classical
encryption techniques, steganography, stream/block ciphers, DES, differential/linear cryptanalysis, cipher
modes, Triple DES, IDEA.
## UNIT-II
Number theory basics (groups, rings, fields, primes, modular arithmetic, Fermat's and Euler's theorems); public
key cryptosystems, RSA algorithm and its security, key management, Diffie-Hellman key exchange, ElGamal
encryption.
## UNIT-III
Message Authentication and Hash Functions: authentication requirements, MAC, hash functions, birthday
attacks, MD5, SHA; Digital Signatures and DSS; authentication applications (Kerberos), email security (PGP,
S/MIME).
## UNIT-IV
IP Security: architecture, authentication header, ESP, key management. Web Security: SSL/TLS, SET. System
Security: intruders, viruses, firewall design principles, trusted systems.
