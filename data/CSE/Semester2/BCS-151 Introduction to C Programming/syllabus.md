# BCS-151 - Introduction to C Programming\n\n**Credits: 5**\n\n## UNIT-I
Basics of programming: problem solving approaches, algorithms and flowcharts, types of computer languages,
assembler/compiler/linker/loader, data types, storage classes, operators, structure of C program, standard I/O,
conditional execution (if/switch), loops (while, do-while, for), break/continue/goto.
## UNIT-II
Arrays: one/multi-dimensional arrays and applications. Strings: string variables and handling functions, array of
strings. Functions: structured programs, user-defined/standard functions, formal vs actual arguments, parameter
passing, recursion, storage classes revisited.
## UNIT-III
Pointers: pointer variable, arithmetic, pointers with arrays/strings/functions, array of pointers, pointer to pointer.
Structure: declaration, initialization, structure as function parameter, structure pointers. Union: declaration,
initialization, union with functions and pointers.
## UNIT-IV
Dynamic Memory Allocation: malloc, calloc, realloc, free. File Management: opening, closing, and I/O operations
on files. Pre-processor directives, macros, command line arguments, introduction to graphics programming.
