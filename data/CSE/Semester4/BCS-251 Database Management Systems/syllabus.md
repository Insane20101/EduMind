# BCS-251 - Database Management Systems\n\n**Credits: 4**\n\n## UNIT-I
Introduction: overview of DBMS, database vs file system, architecture, data models, schema and instances, data
independence, DDL/DML, ER model concepts, notation, mapping constraints, keys, generalization, aggregation,
extended ER model.
## UNIT-II
Relational Data Model: integrity constraints (entity, referential, key, domain), relational algebra and calculus.
SQL: data types, commands, operators, tables/views/indexes, queries/sub-queries, aggregate functions, joins,
cursors, triggers, PL/SQL procedures.
## UNIT-III
Database Design & Normalization: functional dependencies, normal forms (1NF, 2NF, 3NF, BCNF), inclusion
dependence, lossless join decompositions, normalization using FD/MVD/JD.
## UNIT-IV
Transaction Processing: serializability, conflict/view serializable schedules, recoverability, log-based recovery,
checkpoints, deadlock handling; Distributed Database concepts; Concurrency Control: locking, timestamping,
validation-based, multiple granularity, multi-version schemes.
