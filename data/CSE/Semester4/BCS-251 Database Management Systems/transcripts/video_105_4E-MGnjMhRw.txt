A primary index is only applied on data if it follows two situations. The first condition is the data file that you are entering in the hard disk, because we want to store data permanently. So, when we store data permanently, what option do we have? Storing in hard disk means storing in secondary memory. So, in the secondary memory, the file that we are storing—that file has two conditions. 

The first condition is order. Order means sorted, ascending or descending—there is no problem in that, but it should be ordered. 

The second is key value. It means it should be unique. So, first, data should be unique, and second, it should be ordered. If both these conditions get fulfilled, then which index will we use? It is a primary index. So this is the condition to apply a primary index. 

If I will give you a simple example: if you are working on Oracle or SQL Server, and there in a table, a table where you make data—meaning create table, table name—in that, when we insert data in the table, if you make a primary key, anything that we have made a primary key (roll number, registration number), then by default, a primary index will apply on it automatically. So, a primary index is basically used based on this: first, your data is ordered, and second, it has a key value—it is unique. 

So, when its index will form, in the index, as we have discussed earlier also, two things are there: first is the key value, and second is the pointer. Key values mean how you have to search data. How to search data? If I take the example of any university or college, so in any university or college, if I have to find any detail of a student online, how will I find it?
