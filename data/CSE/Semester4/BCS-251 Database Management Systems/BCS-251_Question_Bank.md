# BCS-251 - Database Management Systems
## Complete Unit-Wise Question Bank (Theory + Numericals, Basic → Advanced)

> **Course:** BCS-251 - Database Management Systems  
> **Credits:** 4  
> **Coverage:** Strictly mapped to the syllabus.

## Syllabus Reference

1. Introduction: overview of DBMS, database vs file system, architecture, data models, schema and instances, data independence, DDL/DML, ER model concepts, notation, mapping constraints, keys, generalization, aggregation, extended ER model.

2. Relational Data Model: integrity constraints (entity, referential, key, domain), relational algebra and calculus. SQL: data types, commands, operators, tables/views/indexes, queries/sub-queries, aggregate functions, joins, cursors, triggers, PL/SQL procedures.

3. Database Design & Normalization: functional dependencies, normal forms (1NF, 2NF, 3NF, BCNF), inclusion dependence, lossless join decompositions, normalization using FD/MVD/JD.

4. Transaction Processing: serializability, conflict/view serializable schedules, recoverability, log-based recovery, checkpoints, deadlock handling; Distributed Database concepts; Concurrency Control: locking, timestamping, validation-based, multiple granularity, multi-version schemes.
