# SCS-211 - Introduction to Data Science
## Complete Unit-Wise Question Bank (Theory + Numericals, Basic → Advanced)

> **Course:** SCS-211 - Introduction to Data Science  
> **Credits:** 3  
> **Coverage:** Strictly mapped to the syllabus.

## Syllabus Reference
### UNIT-I
Introduction to Data Science, sectors using data science, purpose and components of Python in data science, applications, ethical issues (privacy, security, ethics).  
### UNIT-II
Data Analytics Process, Exploratory Data Analysis (EDA) - quantitative and graphical techniques, data analytics conclusions and predictions.  
### UNIT-III
Feature Generation and Feature Selection: motivating application (customer retention), feature generation (brainstorming, domain expertise), feature selection algorithms.  
### UNIT-IV
Data Visualization: basic principles, ideas and tools, examples of industry projects, creating visualizations of complex datasets.
