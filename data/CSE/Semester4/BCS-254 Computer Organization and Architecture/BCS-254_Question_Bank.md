# BCS-254 - Computer Organization and Architecture
## Complete Unit-Wise Question Bank (Theory + Numericals, Basic → Advanced)

> **Course:** BCS-254 - Computer Organization and Architecture  
> **Credits:** 5  
> **Coverage:** Strictly mapped to the syllabus.

## Syllabus Reference
UNIT-I: Basics: functional blocks, floating point representation, computer arithmetic, addressing modes, instruction set and execution flow, instruction formats, data transfer/manipulation/arithmetic/logic operations, shift micro-operations.  
UNIT-II: Design of Arithmetic Circuits: addition/subtraction of signed numbers, multiplication, integer division, fast adders/multipliers, floating point operations, decimal arithmetic, arithmetic and instruction pipeline; Control Design: hardwired and micro-programmed control.  
UNIT-III: Memory hierarchy, cache memory principles (address, size, mapping, replacement, write policy), internal memory (RAM/ROM), external memory (hard disk, RAID), virtual memory concept.  
UNIT-IV: I/O modules: programmed I/O, polling, interrupt-driven I/O, DMA, synchronous/asynchronous serial communication, computer peripherals.

## UNIT I — Basics
### Section A: Definitions & Concept Questions (Basic, 2–3 Marks)

1. **[Unit I | Topic: Functional Blocks | Type: Theory | Difficulty: Basic]**  
   Define the functional blocks of a computer system and explain their roles.

2. **[Unit I | Topic: Floating Point Representation | Type: Theory | Difficulty: Basic]**  
   What is floating point representation? Describe its components.

3. **[Unit I | Topic: Addressing Modes | Type: Theory | Difficulty: Basic]**  
   List and explain any three addressing modes used in instruction sets.

### Section B: Computational & Applied Problems (Intermediate, 7 Marks)

1. **[Unit I | Topic: Computer Arithmetic | Type: Numerical | Difficulty: Intermediate]**  
   Perform the addition of two 8-bit binary numbers: 10111010 and 10010101. Show all steps.

2. **[Unit I | Topic: Instruction Formats | Type: Numerical | Difficulty: Intermediate]**  
   Given an instruction format of 16 bits with an opcode of 4 bits and address field of 12 bits, explain how you would decode an instruction with the opcode `1010` and address `000011001111`.

### Section C: Advanced Theory & Numericals

1. **[Unit I | Topic: Execution Flow | Type: Theory | Difficulty: Advanced]**  
   Discuss the execution flow of an instruction in a typical CPU architecture, including fetch, decode, and execute phases.

2. **[Unit I | Topic: Shift Micro-Operations | Type: Numerical | Difficulty: Advanced]**  
   Given a 4-bit register containing the value `1101`, perform a left shift operation and a right shift operation, stating the results.
