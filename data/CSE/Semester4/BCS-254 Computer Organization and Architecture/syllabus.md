# BCS-254 - Computer Organization and Architecture\n\n**Credits: 5**\n\n## UNIT-I
Basics: functional blocks, floating point representation, computer arithmetic, addressing modes, instruction set
and execution flow, instruction formats, data transfer/manipulation/arithmetic/logic operations, shift
micro-operations.
## UNIT-II
Design of Arithmetic Circuits: addition/subtraction of signed numbers, multiplication, integer division, fast
adders/multipliers, floating point operations, decimal arithmetic, arithmetic and instruction pipeline; Control
Design: hardwired and micro-programmed control.
## UNIT-III
Memory hierarchy, cache memory principles (address, size, mapping, replacement, write policy), internal
memory (RAM/ROM), external memory (hard disk, RAID), virtual memory concept.
## UNIT-IV
I/O modules: programmed I/O, polling, interrupt-driven I/O, DMA, synchronous/asynchronous serial
communication, computer peripherals.
