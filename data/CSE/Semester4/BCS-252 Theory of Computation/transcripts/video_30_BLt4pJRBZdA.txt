Hello everyone. Today, let's explain how to remove unit productions from the grammar. Let's say we are given a grammar, and we need to remove the unit productions. First, we need to recognize what a unit production is. All the productions which are in the form like $\alpha \to \beta$, and both $\alpha$ and $\beta$ belong to the variables, are called unit productions. That is, if $\alpha \to \beta$ where both $\alpha$ and $\beta$ belong to the set of variables. 

Here, are these unit productions? Let's check: $S \to A \mid B$. Here, $S$ is a variable, and $A$ and $B$ are also variables. So, $\alpha \to \beta$ where both are variables, meaning this is a unit production. A terminal should not be there; only a single variable should be on the right-hand side. So look at this type of grammar: $A \to a$, because this has a small 'a', which is a terminal. Next, $B \to C$. Yes, here $B$ and $C$ are both variables, so this is a unit production. Since $C$ is a variable and $B$ is a variable, $B \to C$ is a unit production. Then $C \to D$. Here, both are variables, so this is a unit production. $D \to E$. Here, both are variables, so this is a unit production. $E \to a$. Here, 'a' is a terminal, so this is not a unit production.

First, we need to recognize where the unit productions are. Then, how do we remove them directly? We can use a dependency graph. Let's see: $S$ points to $A$ and $B$. $A$ points to nothing (it has a terminal). $B$ points to $C$. $C$ points to $D$. $D$ points to $E$. $E$ points to a terminal. So, we can make a graph like this. 

However, we can also use the transitive property. According to the transitive property, if we have something like $D \to E$, if I remove this production and just drop $E$, will I suffer any loss? We must not suffer any loss, because the new grammar we get after removing the unit production must produce the exact same language as the original grammar. It should not be that the new grammar produces a totally different language; both must produce the same language. 

So, how do we fix this? Let's look at the algorithm. $D \to E$, and $E \to a$. If I remove $E$ from here, $D$ should now produce what $E$ produced. What did $E$ produce? $E$ produced 'a'. So, $D$ should now produce 'a'. We check what $E$ recognizes: $E$ recognizes 'a', so $D$ will now recognize 'a'. Simply, wherever there is $E$, we write 'a'. 

Next, $C \to D$. If we remove $D$ from here, what does $D$ produce? $D$ produces 'a'. So, we remove the unit production where $D$ is, and since $C$ points to $D$, $C$ should produce what $D$ produces. This is how you have to remove it. Using the dependency graph, we see what each variable produces, and we substitute it. $C$ produces what $D$ produces, which is 'a'. 

Similarly, for $B \to C$, if we remove $C$, what does $C$ produce? $C$ produces 'a'. So, we write $C$'s production (which is 'a') right here for $B$, because $B$ already produces it. Thus, $B$ produces the terminal 'a'. Now, do we have any unit productions left? No, we have successfully removed all unit productions.

Next, after removing unit productions, we need to check if there are any unreachable productions. Unreachable means productions that cannot be reached from the start symbol $S$. From $S$, we can reach $A$ and $B$, and from $A$ and $B$, we can produce things. But can we reach $C$, $D$, and $E$ from the starting symbol $S$? We can go to $A$ and $B$ from $S$, but can we go to $C$, $D$, or $E$? No, $C$, $D$, and $E$ cannot be produced from $S$, meaning they are unreachable. So, you can simply remove them. This is how you get your final grammar after removing unit productions.

Let's look at another example. Suppose we are given the following productions: $S \to BA$, $S \to b$, $A \to B$, $A \to a$, $B \to AA$, $B \to b$. Let's identify the unit productions here. $S \to B$ and $A \to B$ are unit productions because they have a single variable on the right-hand side. 

Let's make a dependency graph for this. $S$ points to $B$, and $A$ points to $B$. By using the transitive property, if we remove $S \to B$, what does $B$ produce? $B$ produces $AA$ and $b$. So if we remove $B$, $S$ should produce what $B$ produces. $B$ produces $AA$ and $b$. And $S$ already had $BA$ and $b$. So, if we remove $S \to B$, we replace $B$ with what $B$ produces, which gives us $AA$ and $b$ (along with the existing ones). According to the transitive property, we write down what $B$ produces: $AA$ and $b$. 

Similarly, for $A \to B$, if we remove $B$ from here, what does $B$ produce? $B$ produces $AA$ and $b$. So, $A$ should now produce what $B$ produces, which are $AA$ and $b$. Both unit productions ($S \to B$ and $A \to B$) are now removed. This is how you find it. 

Now, let's check which states are reachable from the starting state. $S$ can reach $A$, but can $S$ reach $B$? Wait, is $B$ reachable from the starting state? We can go from $S$ to $A$, but can we go to $B$ directly from the starting symbol? No, $B$ is not reachable from the starting symbol (there is no production leading directly to just $B$ as a start of a string, or rather, $B$ isn't reachable). Therefore, you can simply remove the productions of $B$ from the grammar. This is your final production set after removing the unit productions.
