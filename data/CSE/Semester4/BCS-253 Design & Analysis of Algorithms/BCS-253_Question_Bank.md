# BCS-253 - Design & Analysis of Algorithms
## Complete Unit-Wise Question Bank (Theory + Numericals, Basic → Advanced)

> **Course:** BCS-253 - Design & Analysis of Algorithms  
> **Credits:** 5  
> **Coverage:** Strictly mapped to the syllabus.

## Syllabus Reference

1. Introduction: algorithms, analyzing algorithms, complexity, growth of functions, performance measurement, sorting and order statistics (shell, quick, merge, heap sort), sorting in linear time, divide and conquer strategy.

2. Greedy Methods: knapsack, minimum spanning trees (Prim's, Kruskal's), single source shortest paths (Dijkstra's, Bellman Ford). Dynamic Programming: multistage graphs, knapsack, all pair shortest paths (Warshal's, Floyd's), resource allocation.

3. Backtracking, Branch and Bound: Travelling Salesman Problem, graph coloring, N-Queen problem, Hamiltonian cycles, sum of subsets. Advanced Data Structures: Red-Black trees, B-trees, Binomial heaps, Fibonacci heaps.

4. Selected Topics: string matching, text processing, theory of NP-completeness, approximation algorithms, randomized algorithms, algebraic computation, Fast Fourier Transform.
