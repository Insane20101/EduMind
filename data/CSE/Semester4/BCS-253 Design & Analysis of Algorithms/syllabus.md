# BCS-253 - Design & Analysis of Algorithms\n\n**Credits: 5**\n\n## UNIT-I
Introduction: algorithms, analyzing algorithms, complexity, growth of functions, performance measurement,
sorting and order statistics (shell, quick, merge, heap sort), sorting in linear time, divide and conquer strategy.
## UNIT-II
Greedy Methods: knapsack, minimum spanning trees (Prim's, Kruskal's), single source shortest paths
(Dijkstra's, Bellman Ford). Dynamic Programming: multistage graphs, knapsack, all pair shortest paths
(Warshal's, Floyd's), resource allocation.
## UNIT-III
Backtracking, Branch and Bound: Travelling Salesman Problem, graph coloring, N-Queen problem, Hamiltonian
cycles, sum of subsets. Advanced Data Structures: Red-Black trees, B-trees, Binomial heaps, Fibonacci heaps.
## UNIT-IV
Selected Topics: string matching, text processing, theory of NP-completeness, approximation algorithms,
randomized algorithms, algebraic computation, Fast Fourier Transform.
