# BCS-201 - Digital Logic and Design\n\n**Credits: 4**\n\n## UNIT-I
Binary Codes - weighted and non-weighted, binary arithmetic, conversion algorithms, error detecting/correcting
codes, canonical/standard Boolean expressions, truth tables.
## UNIT-II
K-Map reduction, don't care conditions, adders/subtractors, carry look-ahead adder, code converters,
equivalence functions, parallel adder/subtractor for signed numbers, magnitude comparator, decoders/encoders,
multiplexers/demultiplexers.
## UNIT-III
Sequential Logic: basic latch, flip-flops (SR, D, JK, T, Master-Slave), triggering, counters (design procedure,
ripple, BCD/binary, synchronous).
## UNIT-IV
Registers: shift registers, registers with parallel load, memory unit (RAM, ROM, PROM, EPROM), reduction of
state and flow tables, race-free state assignment, hazards.
