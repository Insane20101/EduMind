# BCS-201 - Digital Logic and Design
## Complete Unit-Wise Question Bank (Theory + Numericals, Basic → Advanced)

> **Course:** BCS-201 - Digital Logic and Design  
> **Credits:** 4  
> **Coverage:** Strictly mapped to the syllabus.

## Syllabus Reference
- UNIT-I: Binary Codes - weighted and non-weighted, binary arithmetic, conversion algorithms, error detecting/correcting codes, canonical/standard Boolean expressions, truth tables.
- UNIT-II: K-Map reduction, don't care conditions, adders/subtractors, carry look-ahead adder, code converters, equivalence functions, parallel adder/subtractor for signed numbers, magnitude comparator, decoders/encoders, multiplexers/demultiplexers.
- UNIT-III: Sequential Logic: basic latch, flip-flops (SR, D, JK, T, Master-Slave), triggering, counters (design procedure, ripple, BCD/binary, synchronous).
- UNIT-IV: Registers: shift registers, registers with parallel load, memory unit (RAM, ROM, PROM, EPROM), reduction of state and flow tables, race-free state assignment, hazards.

## UNIT I — Binary Codes and Boolean Algebra
### Section A: Definitions & Concept Questions (Basic, 2–3 Marks)

1. **[Unit I | Topic: Binary Codes | Type: Theory | Difficulty: Basic]**  
   Define weighted and non-weighted binary codes with examples.

2. **[Unit I | Topic: Binary Arithmetic | Type: Theory | Difficulty: Basic]**  
   Explain binary addition and subtraction with suitable examples.

3. **[Unit I | Topic: Conversion Algorithms | Type: Theory | Difficulty: Basic]**  
   Describe the procedure to convert binary numbers to decimal.

### Section B: Computational & Applied Problems (Intermediate, 7 Marks)

1. **[Unit I | Topic: Error Detecting Codes | Type: Theory | Difficulty: Intermediate]**  
   Given a binary number, explain how to detect errors using a parity bit.

2. **[Unit I | Topic: Canonical Boolean Expressions | Type: Theory | Difficulty: Intermediate]**  
   Convert the given truth table into its canonical form.

### Section C: Advanced Theory & Numericals

1. **[Unit I | Topic: Truth Tables | Type: Theory | Difficulty: Advanced]**  
   Derive the truth table for the given Boolean expression: A'B + AB'.

2. **[Unit I | Topic: Binary Arithmetic | Type: Theory | Difficulty: Advanced]**
