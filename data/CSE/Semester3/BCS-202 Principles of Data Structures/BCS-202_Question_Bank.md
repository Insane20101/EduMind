# BCS-202 - Principles of Data Structures
## Complete Unit-Wise Question Bank (Theory + Numericals, Basic → Advanced)

> **Course:** BCS-202 - Principles of Data Structures  
> **Credits:** 5  
> **Coverage:** Strictly mapped to the syllabus.

## Syllabus Reference
UNIT-I: Introduction: basic terminology, elementary data organization, complexity and time-space trade-off. Arrays: representation, analysis, address calculation, applications. Stacks: array/linked representation, operations, applications, infix-prefix-postfix conversion, Tower of Hanoi.  
UNIT-II: Queues: array/linked representation, operations, circular queues, D-queues, priority queues. Linked List: singly linked lists, two-way header list, traversing/searching, insertion/deletion, doubly linked list, generalized linked list, garbage collection.  
UNIT-III: Trees: basic terminology, binary trees, representation, complete/extended binary trees, traversal, threaded binary trees, Huffman algorithm. Binary Search Trees: BST, insertion/deletion, complexity, AVL trees, B-trees.  
UNIT-IV: Searching and Hashing: sequential/binary search, hash table, hash functions, collision resolution. Sorting: insertion, bubble, quick, merge, heap sort. Graphs: terminology, representations, traversal, connected components, minimum cost spanning trees.

## UNIT I — Introduction to Data Structures
### Section A: Definitions & Concept Questions (Basic, 2–3 Marks)

4. **[Unit I | Topic: Stacks | Type: Theory | Difficulty: Basic]**

### Section B: Computational & Applied Problems (Intermediate, 7 Marks)

1. **[Unit I | Topic: Address Calculation | Type: Numerical | Difficulty: Intermediate]**

2. **[Unit I | Topic: Stack Operations | Type: Numerical | Difficulty: Intermediate]**

3. **[Unit I | Topic: Tower of Hanoi | Type: Numerical | Difficulty: Intermediate]**

### Section C: Advanced Theory & Numericals
