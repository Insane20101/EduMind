A single-linked list consists of nodes. Every node is divided into two parts: the first part contains data, while the other contains the address of the next node. The address part keeps all the nodes interconnected. 

As you know, the linked list uses dynamic allocation. In dynamic allocation, we can add and delete a node at runtime. For example, there is an organization which has a number of employees. If we create a linked list of the employees, like 1, 2, 3, 4... We created the linked list because the employees may join as well as leave the organization. Employees are never permanent. So we created a linked list. We use linked lists in such organizations.
