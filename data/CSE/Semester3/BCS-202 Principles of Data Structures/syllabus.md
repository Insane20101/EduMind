# BCS-202 - Principles of Data Structures\n\n**Credits: 5**\n\n## UNIT-I
Introduction: basic terminology, elementary data organization, complexity and time-space trade-off. Arrays:
representation, analysis, address calculation, applications. Stacks: array/linked representation, operations,
applications, infix-prefix-postfix conversion, Tower of Hanoi.
## UNIT-II
Queues: array/linked representation, operations, circular queues, D-queues, priority queues. Linked List: singly
linked lists, two-way header list, traversing/searching, insertion/deletion, doubly linked list, generalized linked list,
garbage collection.
## UNIT-III
Trees: basic terminology, binary trees, representation, complete/extended binary trees, traversal, threaded
binary trees, Huffman algorithm. Binary Search Trees: BST, insertion/deletion, complexity, AVL trees, B-trees.
## UNIT-IV
Searching and Hashing: sequential/binary search, hash table, hash functions, collision resolution. Sorting:
insertion, bubble, quick, merge, heap sort. Graphs: terminology, representations, traversal, connected
components, minimum cost spanning trees.
