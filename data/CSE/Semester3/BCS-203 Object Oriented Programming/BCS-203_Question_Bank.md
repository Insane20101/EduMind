# BCS-203 - Object Oriented Programming
## Complete Unit-Wise Question Bank (Theory + Numericals, Basic → Advanced)

> **Course:** BCS-203 - Object Oriented Programming  
> **Credits:** 5  
> **Coverage:** Strictly mapped to the syllabus.

## Syllabus Reference

1. Introduction to OOP principles, Core Java: introduction, operators, data types, variables, control statements, arrays, methods and classes, constructors, string handling, inheritance, packages and interfaces.

2. Exception Handling, multithread programming, I/O, Java Applet, Networking, Event handling, introduction to AWT, AWT controls, layout managers.

3. Java Swing: creating a swing applet, labels, text fields, buttons, tabbed panes. JDBC: connectivity model, JDBC/ODBC bridge, JAVA SQL package, remote database connectivity, RMI.

4. Java Beans: application builder tools, BDK, JAR files, introspection, developing a bean, bound properties, Java Beans API, Session Beans, Entity Beans, introduction to Java Servlet: basics, API, life cycle.
