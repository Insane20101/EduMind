I gave you three adjectives, three shop names, and three other words, stating that you should choose one from each category. To achieve this, I will generate a random number. I will declare `let rand = Math.random();` This function generates a random number between 0 and 1. The core logic involves dividing the 0 to 1 interval into three equal pieces. If we consider 30% or roughly one-third, we can establish three ranges: 0 to 0.33, 0.33 to 0.66, and 0.66 to 1. Each of these ranges represents approximately one-third of the total interval (1/3 or 0.33, 2/3 or 0.66, and 3/3 or 1). Any random number generated will fall into one of these three equally sized ranges.

So, once I have this random number, I will use `if/else if/else` statements. The business name will be composed of three parts: `first`, `second`, and `third`. If `rand` is less than 0.33, `first` will be assigned "Crazy." Otherwise, if `rand` is less than 0.66 (and by extension, greater than or equal to 0.33), `first` will be updated to "Amazing." In all other cases (if `rand` is greater than or equal to 0.66), `first` will be "Fire." This approach is necessary because the challenge explicitly stated that arrays could not be used.

Similarly, I will generate the second word. I'll duplicate the code block for the first word using Alt+Shift+Down Arrow (I'm showing you this with screencast mode on). I'll copy the logic and adapt it for the `second` word, changing the variable name. The options for the second word are "Engine," "Foods," and "Garments." "Engine" will be assigned if the random number falls in the first range, "Foods" for the second range, and "Garments" for the third. I will repeat the same process for the `third` word, using "Bros," "Limited," and "Hub" as options.

Finally, the complete business name will be a concatenation of `first`, `second`, and `third`. I'll use a backtick for a template literal in `console.log()`: `console.log(`${first} ${second} ${third}`);`. When I preview this in the browser and open the console, you can see it generates a name. For example, "Crazy Engine Pros." If I reload, it generates another name, "Amazing Foods Limited."

After some reloads, I noticed a problem: the names were not as varied as expected. For instance, it kept giving "Amazing Foods Limited" or "Fire Garments." I realized what was happening: I was generating only one random number for all three word selections. To get a truly random combination, I need to update the random number for each part of the name. So, I will generate a new `rand` variable for the `first` word, a separate `rand` for the `second` word, and another `rand` for the `third` word. This ensures that each word is selected independently.

Now, with this correction, when I reload, you will see a much wider variety of names: "Amazing Foods Limited," "Amazing Garments," "Fire Garments," "Crazy Engine Limited," "Fire Garments Bros," and so on. Many unique names are generated. You could even use a `for` loop to generate many combinations or explore all possible combinations. I used three categories here: Adjective, Shop Name, and a Concluding Word. If I had used more categories or more options within each category, even more unique names could have been generated.
