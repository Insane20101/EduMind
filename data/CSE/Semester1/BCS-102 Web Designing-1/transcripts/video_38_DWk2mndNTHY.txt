Now, let’s dive into some concepts of flexbox. The first concept is that items in flexbox are not always laid out from left to right; they follow the `flex-direction`. By default, the direction is left to right, but it can be changed. If I set the property `flex-direction: column`, the items will be arranged from top to bottom.

Now, let’s clarify the concepts of the main axis and cross axis. When `flex-direction` is set to row, the items will be laid out along the main axis, while the cross axis will be perpendicular. If I change `flex-direction` to column, the main axis will shift accordingly, and the cross axis will also change.

The properties `justify-content` and `align-items` work according to the main axis and cross axis. When you use `justify-content: center`, it centers the items along the main axis. Many beginners mistakenly think that it only centers horizontally, but it actually depends on the direction of the main axis.

To clarify further, if the main axis is row, `justify-content: center` will center items horizontally. If the main axis is column, it will center items vertically. Similarly, `justify-content: flex-start` will align items at the start of the main axis, while `flex-end` will align them at the end.

Now, let’s discuss the concepts of main size and cross size. The distance from the main axis to the edge is referred to as the main size, while the distance from the cross axis to the edge is called the cross size.
