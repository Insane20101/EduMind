Learning the concept of inline and block elements in HTML is very important. Inline elements are those which take only as much width as required, while block elements take the full width of the screen. This is also referred to as the display property, which can be set through CSS.

This happens because the paragraph is a block element, and the anchor tag is an inline element. Inline elements only take up as much space as they need, while block elements take the entire width, causing the next content to appear below.

For further clarification, if I talk about the `<div>` element, it is a block element, while the `<span>` element is an inline element. I can place an inline element, like an anchor tag, alongside a span element because inline elements allow other elements to occupy their width. 

Now, will the anchor tag always be inline? Will the paragraph tag always be block? The answer is no. You can change the display property of any element with CSS. This means that an inline element can be made block, and a block element can be made inline. We will explore this in CSS later.
