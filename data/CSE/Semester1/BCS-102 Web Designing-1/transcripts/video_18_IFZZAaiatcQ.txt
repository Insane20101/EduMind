**Why are Arrays Used?**

Arrays are used to store multiple values under a single name. For example, if I create an array named `fruits`, I can put `banana`, `apple`, and `grapes` inside it. Different data types can also exist under the same name.

When we actually do web development, arrays are essential. You will use arrays when creating components in React, especially if you need to generate multiple instances of the same component. Consider a blog; you'll see repeated cards, each representing a blog article. Each card will correspond to an object within an array.

For instance, an array might contain objects like:
```javascript
[{
  title: "Should I become a technology specialist or journalist?",
  category: "Technology",
  description: "..."
},
{
  title: "Another blog post",
  category: "General",
  description: "..."
}]
```
These items will be given to you as an array of objects, and your job will be to display them on the UI using React. We will cover those details later, but for now, let's focus on what an array is.

If you `console.log(arr)`, it will display an array with its elements and length. For example, it might show "Array(5) [1, 2, 4, 5, 7]".

**Array Length**

To find the number of elements in an array, use the `.` operator followed by `length`. Just like with strings, `arr.length` will return the array's length. Note that `length` is a property, not a function, so you don't use parentheses.

**Mutability vs. Immutability: Arrays vs. Strings**

Arrays are **mutable**, meaning you can change their contents after they are created. Strings, however, are **immutable**. When you perform an operation on a string, it returns a *new* string, leaving the original string intact. In contrast, changing an array modifies the original array directly. This is a fundamental difference: strings are immutable, and arrays are mutable.

**Accessing and Modifying Array Elements by Index**

Array elements are accessed using zero-based indexing.
For the array `arr = [1, 2, 4, 5, 7]`:
*   `arr[0]` will give you `1`.
*   `arr[1]` will give you `2`.
*   `arr[3]` will give you `5`.

The indices are:
`0: 1`
`1: 2`
`2: 4`
`3: 5`
`4: 7`

You can also change the value of an array element by assigning a new value to a specific index:
```javascript
arr[0] = 5666;
console.log(arr); // Output: [5666, 2, 4, 5, 7]
```
This directly changes the original array. In contrast, attempting to change a character in a string at a specific index will not work because strings are immutable.
```javascript
let str = "Harry";
str[0] = "J"; // This will not change the string
console.log(str); // Output: "Harry"
```

**`typeof` Operator with Arrays**

If you use `typeof` on an array, it returns `"object"`. In JavaScript, arrays are a specialized type of object.
```javascript
console.log(typeof arr); // Output: "object"
```

**Common Array Methods**

There are many built-in methods to manipulate arrays.

1.  **`toString()`**: Converts an array into a comma-separated string.
    ```javascript
    let arr = [1, 2, 4, 5, 7];
    let arrString = arr.toString();
    console.log(arrString); // Output: "1,2,4,5,7" (a string)
    ```
    This method is useful when you need to represent array data as a string.

2.  **`join()`**: Joins all elements of an array into a string, using a specified separator.
    ```javascript
    let arr = [1, 2, 4, 5, 7];
    let joinedString = arr.join(" & ");
    console.log(joinedString); // Output: "1 & 2 & 4 & 5 & 7"
    ```
    This is often used in frontend UI development to display lists of items.

3.  **`pop()`**: Removes the last element from an array and returns that element. It modifies the original array.
    ```javascript
    let a = [1, 2, 3, 4, 5, 6];
    let poppedElement = a.pop(); // poppedElement will be 6
    console.log(a); // Output: [1, 2, 3, 4, 5]
    console.log(poppedElement); // Output: 6
    ```

4.  **`push()`**: Adds one or more elements to the end of an array and returns the new length of the array. It modifies the original array.
    ```javascript
    let a = [1, 2, 3, 4, 5];
    let newLength = a.push(100); // newLength will be 6
    console.log(a); // Output: [1, 2, 3, 4, 5, 100]
    a.push("Harry");
    console.log(a); // Output: [1, 2, 3, 4, 5, 100, "Harry"]
    ```

5.  **`shift()`**: Removes the first element from an array and returns that removed element. It modifies the original array.
    ```javascript
    let a = [1, 2, 3, 4, 5];
    let shiftedElement = a.shift(); // shiftedElement will be 1
    console.log(a); // Output: [2, 3, 4, 5]
    console.log(shiftedElement); // Output: 1
    ```
    `pop()` removes from the end, `shift()` removes from the beginning.

6.  **`unshift()`**: Adds one or more elements to the beginning of an array and returns the new length of the array. It modifies the original array.
    ```javascript
    let a = [2, 3, 4, 5];
    let newLength = a.unshift("Jack"); // newLength will be 5
    console.log(a); // Output: ["Jack", 2, 3, 4, 5]
    ```
    `push()` adds to the end, `unshift()` adds to the beginning.
    *Self-correction note: `shift` is to `pop` as `unshift` is to `push`. Please write this in the comments for better recall.*

7.  **`delete` Operator**: The `delete` operator can be used to remove an element at a specific index, but it leaves an empty slot (or `undefined`) in the array. It does not change the array's length.
    ```javascript
    let a = [1, 2, 3, 4, 5, 6, 7];
    delete a[6];
    console.log(a); // Output: [1, 2, 3, 4, 5, 6, <1 empty item>]
    console.log(a.length); // Output: 7 (length remains unchanged)
    console.log(a[6]); // Output: undefined
    ```
    This behavior is important for interviews: memory is still allocated for that index, but no value is present.

8.  **`concat()`**: Joins two or more arrays and returns a *new* array. It does not change the existing arrays.
    ```javascript
    let a1 = [1, 2];
    let a2 = [3, 4];
    let a3 = [5, 6];
    let newArray = a1.concat(a2, a3);
    console.log(newArray); // Output: [1, 2, 3, 4, 5, 6]
    console.log(a1); // Output: [1, 2] (original arrays unchanged)
    ```

9.  **`sort()`**: Sorts the elements of an array in place (modifies the original array) and returns the sorted array. By default, it sorts alphabetically. For numbers, you typically provide an optional `compare` function.
    ```javascript
    let arr = [5, 2, 8, 1, 9];
    arr.sort(); // Sorts as strings: [1, 2, 5, 8, 9] (in this case, works for single digits)
    console.log(arr);

    let numbers = [10, 2, 1, 5];
    numbers.sort((a, b) => a - b); // Sorts numerically in ascending order
    console.log(numbers); // Output: [1, 2, 5, 10]
    ```

10. **`splice()`**: Changes the contents of an array by removing or replacing existing elements and/or adding new elements in place. It modifies the original array and returns the removed elements.
    It takes arguments: `start_index`, `delete_count`, `item1`, `item2`, ...
    *   **Removing elements:**
        ```javascript
        let numbers = [1, 2, 3, 4, 5];
        let removed = numbers.splice(1, 2); // Start at index 1, delete 2 elements (2 and 3)
        console.log(numbers); // Output: [1, 4, 5]
        console.log(removed); // Output: [2, 3]
        ```
    *   **Adding elements:**
        ```javascript
        let numbers = [1, 2, 3, 4, 5];
        // At index 1, delete 0 elements, add 'X', 'Y', 'Z'
        numbers.splice(1, 0, 'X', 'Y', 'Z');
        console.log(numbers); // Output: [1, "X", "Y", "Z", 2, 3, 4, 5]
        ```
    *   **Replacing elements:**
        ```javascript
        let numbers = [1, 2, 3, 4, 5];
        // At index 1, delete 3 elements (2, 3, 4), add 222, 333
        numbers.splice(1, 3, 222, 333);
        console.log(numbers); // Output: [1, 222, 333, 5]
        ```

11. **`slice()`**: Returns a shallow copy of a portion of an array into a new array. It does not modify the original array.
    It takes arguments: `start_index` (inclusive), `end_index` (exclusive).
    *   **From start index to end:**
        ```javascript
        let numbers = [1, 2, 3, 4, 5];
        let newArr = numbers.slice(2); // Start from index 2 to the end
        console.log(newArr); // Output: [3, 4, 5]
        ```
    *   **Between two indices:**
        ```javascript
        let numbers = [1, 2, 3, 4, 5];
        let newArr = numbers.slice(1, 3); // Start from index 1 (inclusive), go up to index 3 (exclusive)
        console.log(newArr); // Output: [2, 3]
        ```

12. **`reverse()`**: Reverses the order of the elements in an array in place (modifies the original array) and returns the reversed array.
    ```javascript
    let arr = [1, 2, 3, 4];
    arr.reverse();
    console.log(arr); // Output: [4, 3, 2, 1]
    ```

**Loops with Arrays**

Loops are crucial for iterating over array elements. I'll demonstrate these in a separate file, `loops.js`, which will be linked to `index.html`.

Let's use an unsorted array: `let a = [1, 3, 5, 6, 88, 93];`

1.  **Classical `for` loop**: The traditional way to iterate using an index.
    ```javascript
    for (let i = 0; i < a.length; i++) {
        console.log(a[i]); // Prints each element
    }
    ```

2.  **`forEach()` loop**: Executes a provided function once for each array element. It can access the `value`, `index`, and the `array` itself.
    ```javascript
    a.forEach((value, index, array) => {
        console.log(`Value: ${value}, Index: ${index}, Array: ${array}`);
    });
    ```
    This will print each element's value, its index, and the full array for every iteration.

3.  **`for...in` loop**: Primarily designed for iterating over enumerable **object properties**. While it *can* be used with arrays, it iterates over indices (keys) as strings, which can lead to unexpected behavior.
    ```javascript
    let obj = { a: 1, b: 2, c: 3 };
    for (const key in obj) {
        // Use obj.hasOwnProperty(key) to avoid inherited properties
        if (obj.hasOwnProperty(key)) {
            console.log(`Key: ${key}, Value: ${obj[key]}`);
        }
    }
    // Output: Key: a, Value: 1; Key: b, Value: 2; Key: c, Value: 3
    ```

4.  **`for...of` loop**: Designed for iterating over **iterable objects** (like arrays, strings, maps, sets). It directly gives you the *values* of the elements. This is the preferred loop for iterating over array elements when you need the values.
    ```javascript
    let a = [1, 3, 5, 6, 88, 93];
    for (const value of a) {
        console.log(value); // Prints each element's value
    }
    ```

**`map()`, `filter()`, and `reduce()` Methods**

These are highly important array methods, especially in modern JavaScript and frameworks like React. I'll demonstrate these in a new file, `mfr.js`.

Let's use the array: `let arr = [1, 3, 5, 7, 11, 13];`

1.  **`map()`**: Creates a *new* array by calling a provided function on every element in the original array. It's used when you want to transform each element into something else.
    *   **Traditional `for` loop approach for squaring values:**
        ```javascript
        let newArr = [];
        for (let i = 0; i < arr.length; i++) {
            newArr.push(arr[i] ** 2);
        }
        console.log(newArr); // Output: [1, 9, 25, 49, 121, 169]
        ```
    *   **`map()` approach for squaring values:**
        ```javascript
        let squaredArr = arr.map(element => element ** 2);
        console.log(squaredArr); // Output: [1, 9, 25, 49, 121, 169]
        ```
        The `map` callback function can also take `index` and `array` as arguments: `arr.map((element, index, array) => { /* ... */ })`. `map` is a concise way to create a new array based on transformations of an existing array.

2.  **`filter()`**: Creates a *new* array with all elements that pass the test implemented by the provided function. It's used when you want to select a subset of elements.
    *   Let's say we want elements from `arr` that are greater than 7.
        ```javascript
        const isGreaterThan7 = (e) => {
            if (e > 7) {
                return true;
            } else {
                return false;
            }
        };
        // Or more concisely: const isGreaterThan7 = (e) => e > 7;

        let filteredArr = arr.filter(isGreaterThan7);
        console.log(filteredArr); // Output: [11, 13]
        ```
        The `filter` method returns a new array containing only the elements for which the callback function returned `true`. Often, the function is directly embedded into the `filter` call for brevity.

3.  **`reduce()`**: Executes a reducer function (that you provide) on each element of the array, resulting in a single output value. It's used when you want to combine all elements into a single value.
    *   Consider an array `array2 = [1, 2, 3, 4, 5, 6]`.
    *   **Multiplication example:**
        ```javascript
        const multiplyReducer = (accumulator, currentValue) => accumulator * currentValue;
        let product = array2.reduce(multiplyReducer);
        console.log(product); // Output: 720 (1*2*3*4*5*6)
        ```
        The `reduce` function works iteratively:
        1.  (1, 2) -> 2
        2.  (2, 3) -> 6
        3.  (6, 4) -> 24
        4.  (24, 5) -> 120
        5.  (120, 6) -> 720
    *   **Addition example:**
        ```javascript
        const addReducer = (accumulator, currentValue) => accumulator + currentValue;
        let sum = array2.reduce(addReducer);
        console.log(sum); // Output: 21 (1+2+3+4+5+6)
        ```
        `reduce` is very powerful for operations like summing, finding maximums, or flattening arrays. While `map` and `filter` are used more frequently in projects, `reduce` is highly versatile for aggregation tasks.

**`Array.from()`**

`Array.from()` creates a new, shallow-copied `Array` instance from an array-like or iterable object. This is useful for converting other collection types or strings into actual arrays.
```javascript
let myString = "hello";
let charArray = Array.from(myString);
console.log(charArray); // Output: ['h', 'e', 'l', 'l', 'o']
```
You can also convert HTML collections (from `document.querySelectorAll()`, for example) into arrays using `Array.from()`.
