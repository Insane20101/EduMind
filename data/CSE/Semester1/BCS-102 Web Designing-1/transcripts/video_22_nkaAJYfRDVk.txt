**Responsive Units**

If you set the width to 2048 pixels and then view it on a smaller device, such as a 1080p monitor with a width of 1920 pixels, your website layout may break. To avoid this, you should use responsive units. Instead of using pixels, you can set the width to 100vw, where VW means viewport width. This means it will take the width of your viewport. 

If I increase the viewport size, the width will adjust accordingly. You can right-click, inspect, and choose responsive mode to see how it behaves. When using VH, the horizontal scrollbar may not appear, which is an advantage of using viewport height units.

Sometimes you want the width of your element to equal the viewport width. For example, if I set it to 80vw, I can center the div by setting `margin: auto`. This means that the left and right margins will be automatically set, centering the div. 

However, keep in mind that `margin: auto` will only center block-level elements. If the element is inline, it will not center. For example, if I change the box to a `<span>`, it will not work the same way.

**Understanding VH and VW**

Now, I want to explain VH. If I want the height of the container to be 80% of the viewport height, I will set it to 80vh. If I want it to take 10% of the viewport height, I will set it to 10vh. This means that as I change the height of the viewport, the container will always take 10% of the viewport height, and the other will take 80%.

VH and VW are very important units. Pixels are our universal unit, which we will continue to use. You cannot avoid pixels; they will always be part of your CSS toolkit.

**Understanding EM and REM**

Next, I want to discuss REM and EM. Let's start with EM. Assume the font size of the container is set to 1em. If the font size of this container is 16px, which is the default, I will add a paragraph with some lorem text. 

Now, I will set the font size of the paragraph to 1em. The computed font size will be 16px, as it inherits the font size from the container. If I change the container's font size to 18px, the paragraph will also inherit that size. 

If I set the paragraph's font size to 1.5em, it will be 1.5 times the inherited size. For example, if the inherited size is 18px, then 1.5em will be 27px. If I set it to 2em, it will be 36px. 

**Understanding REM**

Now, let’s talk about REM. Assume I change the font size of the root element (HTML) to 12px. If I set a font size of 2rem, it will be 2 times the root font size, which is 24px. 

REM means the font size is based on the root element, while EM is based on the parent element. If I set the root font size back to 16px, and then set a paragraph to 2em, it will be 32px because it is 2 times the inherited size from the container. 

If I change the root font size to 12px, everything will inherit from there. If I set it to 2rem, it will be 24px. If I set it to 18px, the font size will be 36px. 

**Conclusion**

These are the most commonly used units in CSS. There are other units, but these are the ones I use most frequently when designing websites. Additionally, there are two more units: Vmin and Vmax. 

Vmin refers to the smaller of the viewport's width or height, while Vmax refers to the larger. For example, if I set a container to 100vmin, it will take 100% of the smaller dimension (either width or height).
