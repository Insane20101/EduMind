Its purpose was to allow styles to change based on the device accessing the website. This was the only purpose of the media rule, which was introduced in CSS2. In CSS3, the name of this media rule was changed to media query.

Now, how does the media query work in CSS3? The syntax of a media query starts with `@media`, indicating that you are writing a media query. You specify which device you want to write the media query for, and before that, you can use `not` or `only`. For example, you can write `@media only screen`, which means it will apply only when viewed on a screen.

A typical syntax of a media query looks like this: `@media not or only [media type]`. After that, you write some expressions, and then you include the CSS code that will be applied when the specified conditions are met.

In most cases, you will write `only` because you want the media query to match only when the media type is screen. Other media types include `all`, `print`, and `speech`. For example, if you want your CSS style to apply only when there is a speech device, you would write `speech`. However, in most cases, you will use `screen`.

After specifying the media type, you can write a condition. For instance, if I write `max-width: 455px`, I can set the background color to blue. If the max width is 455 pixels, the background color will be blue.
