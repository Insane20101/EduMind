In today's video, I will tell you about CSS transforms. There are two types of transforms in CSS: 2D transforms and 3D transforms. A 2D transform means we want to change any object in two-dimensional space. For example, we can increase its scale, translate it, or rotate it. A 3D transform, on the other hand, works in three dimensions, which includes an additional axis, the z-axis. This allows us to manipulate an object in three dimensions.

**Transform Property**

Now, what does the transform property do? The transform property applies various transformations to the element. The first transform I want to show you is rotate. Suppose I want to rotate the box. I will set the transform property to rotate. 

You can see that rotate has 3D options: rotate X, rotate Y, and rotate Z. I will show you how to rotate it. Let's say I want to rotate it by 40 degrees. If I turn it 5 times, it will rotate 180 degrees, and 1 turn means it will rotate 360 degrees. We can also rotate it around an axis. For example, I can say `transform: rotateX(40deg)`, which will rotate it around the x-axis.

**Scale Property**

I hope you understood this. Now, let's move on to the scale property. With scale, you can make an object bigger or smaller. If I write `transform: scale(1.5)`, it will increase the size by 1.5 times. If I want it to be bigger in the x-direction, I can use `scaleX`, and if I want it to be bigger in the y-direction, I can use `scaleY`. 

You can also use `scale3D`, which applies a 3D transformation. 

**Skew Property**

Now, let's talk about skew. If I apply `skew(5deg)`, it will skew the box as if someone pulled it from two sides. You can also skew in the y-axis, but remember that skew is not applicable for the z-axis. 

**Translate Property**

Next, we have the translate property, which is the most commonly used property. For example, if I say `translate(34px)`, it will move the box by 34 pixels. If I say `translate(34%)`, it will translate based on its width. I can also translate in the x and y directions. 

Sometimes, we need to apply more than one transform property. When we do this, we can apply them with spaces. For example, if I want to skew in the x direction and translate in the x direction, I can write `transform: skewX(40deg) translateX(45%)`. 

**Using Multiple Transform Properties**

I hope you understood how to apply multiple transform properties. When is transform used? Mainly when we are making a navigation bar, and I want the nav bar to be hidden, I can translate it to -100 pixels, so it will move out of view. 

For example, if I set `margin: 0` and `padding: 0`, and then apply `translateY(-100%)`, it will move out of the view. Similarly, if I apply `translateX(-45%)`, it will move in the negative direction along the x-axis. 

**Transform Origin**

Now, there is one more property called transform origin. This property defines the point around which the transformation occurs. By default, the transform origin is set to 50% for both x and y, meaning it rotates around the center. 

If I set it to `transform-origin: 0 0`, the rotation will occur around the top-left corner. If I increase the value, the rotation point will move accordingly.
