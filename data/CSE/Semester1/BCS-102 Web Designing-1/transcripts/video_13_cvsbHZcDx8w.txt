Suppose you want to write "3 is greater than 4" in HTML. If you try to write `3 > 4` directly in HTML, the preview will show "3 is greater than 4" as written. However, if I write `<p>This is a para</p>` in the content, it will not appear as literal text. This is because HTML interprets `<p>` as a paragraph tag, not as simple text. To avoid this conflict, we use HTML entities.

HTML entities allow you to display characters that have special meaning in HTML syntax. For example, `&lt;` (ampersand, lt, semicolon) represents the less-than symbol (`<`), and `&gt;` (ampersand, gt, semicolon) represents the greater-than symbol (`>`). If you replace `<` with `&lt;` and `>` with `&gt;`, they will appear exactly as written. HTML entities are used to render things that might otherwise collide with HTML's syntax.

For situations where you want to display content with preserved formatting, including spaces and newlines, you can use the `<pre>` tag. If you place anything inside a `<pre>` tag, such as `<pre>p this is a para</pre>`, it will render exactly as you typed it. If you include multiple newlines and spaces, they will all be preserved. However, note that `<pre>` preserves formatting for content, but to display actual HTML tags as text, you still need to use HTML entities.

Other useful HTML entities include `&copy;` for the copyright symbol. You can experiment with various special symbols using HTML entities. A very important entity is `&nbsp;`, which stands for a non-breaking space. If I write "Copyright Code with Harry" with many spaces in between, HTML will ignore the extra spaces, and it will appear as "Copyright CodewithHarry." To force multiple spaces, you need to use `&nbsp;` repeatedly. Each `&nbsp;` you add will create one space. Therefore, whenever you need to add specific spacing in your HTML code, `&nbsp;` is the entity to use. HTML entities are crucial for displaying reserved characters like `<` and `>` and for controlling spacing.

Next, let's discuss quotation tags. The `<blockquote>` tag is used for block quotations, while the `<q>` tag is used for inline quotations. Both can include a `cite` attribute to specify the URL of the source. For example, you can write `<blockquote cite="URL">This is a quotation.</blockquote>` or `<q cite="URL">This is an inline quote.</q>`. Search engines recognize these tags as actual quotations, and you can style them using CSS. These tags are useful for citing research articles, Wikipedia content, or any other textual source.

There are also some HTML tags that are now considered obsolete. The `<font>` tag, for instance, is obsolete because font styling (color, size, etc.) is handled entirely with CSS. Similarly, the `<center>` tag, which was used for centering content, is no longer recommended. Modern CSS techniques like Flexbox and Grid are used for layout and alignment. It's important to be aware of these obsolete tags but understand that you should not use them in modern web development.

For displaying code, the `<code>` tag is essential for coders. On `codevitary.com`, for example, the code snippets are enclosed within `<code>` tags. For syntax highlighting, I use a library called Prism.js. This library highlights code as you see on the website, making it suitable for blogs and documentation. To display multi-line code with preserved formatting and literal HTML tags, you typically combine the `<pre>` and `<code>` tags: `<pre><code>...your code...</code></pre>`. The `<pre>` tag ensures that new lines and spaces are maintained.

Let's demonstrate displaying HTML boilerplate code. If I write standard HTML boilerplate directly, it will render as an HTML page. To display the *code* of the boilerplate as text, I first create the boilerplate. Then, I replace all `<` symbols with `&lt;` and all `>` symbols with `&gt;`. Once these replacements are made, I can paste the modified code inside a `<pre><code>` block. This ensures that the code appears exactly as written, with all tags visible and formatting preserved. If there are unwanted indentations from the `<pre>` tag, you can remove them by selecting the indented lines and pressing Shift + Tab, which reduces one indent level. You can then further refine the spacing. This entire code block can then be styled using CSS, for example, with Prism.js.

Finally, let's briefly touch on character sets and the `<canvas>` element. Character sets define which characters are used on your page (e.g., UTF-8). The `<canvas>` element is an HTML element used for drawing graphical shapes, primarily manipulated through JavaScript.
