# BCS-352 - Software Engineering\n\n**Credits: 4**\n\n## UNIT-I
Software Process: introduction, engineering paradigm, life cycle models (waterfall, incremental, spiral,
evolutionary, prototyping); software requirements - functional/non-functional, requirement engineering process,
feasibility studies, prototyping.
## UNIT-II
Software Design: architectural and low-level design, modularization, structure charts, pseudo codes,
coupling/cohesion; design strategies - function/object oriented; software measurement and metrics - Halstead's
software science, function points, cyclomatic complexity.
## UNIT-III
Software Testing: taxonomy of testing levels, black box testing, boundary conditions, structural testing,
regression testing; testing strategies - unit, integration, validation, system testing and debugging.
## UNIT-IV
Measures and Measurements: Zipf's law, software cost estimation (Function Point, COCOMO), Delphi method,
scheduling, earned value analysis, error tracking, software configuration management, project
planning/scheduling, risk management, CASE tools.
