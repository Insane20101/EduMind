# SCS-313/323/333 - Department Minor (Web Data Mining / Embedded Systems for IoT / Scientific & Engineering Data Visualization)\n\n**Credits: 4**\n\nWeb Data Mining
Association rules and sequential patterns (Apriori, GSP); information retrieval, text/web page preprocessing,
inverted index; link analysis (PageRank, HITS), community discovery, web crawling; opinion mining and web
usage mining.
Embedded Systems for IoT
IoT specification and design of embedded systems (sensors, actuators, processors); digital/analog I/O, PWM,
SD card interfacing; IoT enabling technologies - RFID, BLE, protocols (MQTT, CoAP), platforms; Web of Things,
Cloud of Things, IoT case studies.
Scientific and Engineering Data Visualization
Visualization overview, data types, scalar visualization techniques (contour, isosurface); flow data visualization
(vector/tensor mapping); volume rendering; applications and case studies, future trends.
