# SCS-313/323/333 - Department Minor (Web Data Mining / Embedded Systems for IoT / Scientific & Engineering Data Visualization)
## Complete Unit-Wise Question Bank (Theory + Numericals, Basic → Advanced)

> **Course:** SCS-313/323/333 - Department Minor (Web Data Mining / Embedded Systems for IoT / Scientific & Engineering Data Visualization)  
> **Credits:** 4  
> **Coverage:** Strictly mapped to the syllabus.

## Syllabus Reference

1. Web Data Mining
   - Association rules and sequential patterns (Apriori, GSP)
   - Information retrieval, text/web page preprocessing, inverted index
   - Link analysis (PageRank, HITS), community discovery, web crawling
   - Opinion mining and web usage mining

2. Embedded Systems for IoT
   - IoT specification and design of embedded systems (sensors, actuators, processors)
   - Digital/analog I/O, PWM, SD card interfacing
   - IoT enabling technologies - RFID, BLE, protocols (MQTT, CoAP), platforms
   - Web of Things, Cloud of Things, IoT case studies

3. Scientific and Engineering Data Visualization
   - Visualization overview, data types, scalar visualization techniques (contour, isosurface)
   - Flow data visualization (vector/tensor mapping)
   - Volume rendering
   - Applications and case studies, future trends

## UNIT I — Web Data Mining
### Section A: Definitions & Concept Questions (Basic, 2–3 Marks)

1. **[Unit I | Topic: Association Rules | Type: Theory | Difficulty: Basic]**  
   What is an association rule in data mining? Provide a simple example.

2. **[Unit I | Topic: Information Retrieval | Type: Theory | Difficulty: Basic]**  
   Define information retrieval and explain its significance in web data mining.

3. **[Unit I | Topic: PageRank | Type: Theory | Difficulty: Basic]**  
   What is PageRank, and how does it contribute to link analysis?

### Section B: Computational & Applied Problems (Intermediate, 7 Marks)

1. **[Unit I | Topic: Apriori Algorithm | Type: Numerical | Difficulty: Intermediate]**  
   Given a dataset of transactions, apply the Apriori algorithm to find frequent itemsets with a minimum support of 50%.

2. **[Unit I | Topic: GSP Algorithm | Type: Numerical | Difficulty: Intermediate]**  
   Explain and demonstrate how to identify sequential patterns in a given sequence database using the GSP algorithm.

### Section C: Advanced Theory & Numericals

1. **[Unit I | Topic: Community Discovery | Type: Theory | Difficulty: Advanced]**  
   Discuss various techniques for community discovery in social networks and their implications in web data mining.

2. **[Unit I | Topic: Opinion Mining | Type: Numerical | Difficulty: Advanced]**  
   Analyze a set of reviews using sentiment analysis techniques to determine the overall opinion trend.
