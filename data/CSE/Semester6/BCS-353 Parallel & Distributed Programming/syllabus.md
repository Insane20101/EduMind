# BCS-353 - Parallel and Distributed Programming\n\n**Credits: 4**\n\n## UNIT-I
Parallel Computing, parallel computer model, architectural classification schemes, multiprocessor systems and
interconnection networks; theoretical foundations - logical clocks, causal ordering, global state, termination
detection.
## UNIT-II
Distributed Mutual Exclusion: classification, requirement theorem, token-based and non-token-based algorithms,
performance metrics.
## UNIT-III
Distributed Deadlock Detection: system models, resource vs communication deadlocks,
prevention/avoidance/detection/resolution, path pushing and edge chasing algorithms; Agreement Protocols:
Byzantine agreement, consensus problem, interactive consistency.
## UNIT-IV
Distributed File Systems: file service architecture, Sun NFS, Andrew File System; Distributed Algorithms:
communication protocols, sliding window protocol, routing algorithms, deadlock-free packet switching, election
algorithms, CORBA.
