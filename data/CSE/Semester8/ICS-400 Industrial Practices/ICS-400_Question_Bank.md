## Syllabus Reference

1. Software Verification and Validation
   - Introduction to V&V; evaluation methods, code inspections
   - Software engineering methods review, economics of V&V;
   - Software reviews/inspections, quality metrics
   - Configuration management, functional/structural testing
   - Integration/system testing
   - Validation metrics, improving the process

2. Modelling and Simulation
   - Introduction to systems and simulation, DES concepts, state/events
   - Probability/statistics, queuing models
   - Random number/variate generation; input/output analysis, distribution fitting
   - Verification and validation of simulation models
   - Simulation tools and techniques
